# Project Scope — LinkLite

## Phase 1: MVP

### Included

- Anonymous URL shortening.
- Short-code generation.
- URL redirection.
- URL validation.
- Duplicate URL detection.
- PostgreSQL persistence.
- REST API.
- Automated testing.
- Basic deployment.

### Excluded

- User registration.
- User authentication.
- User dashboards.
- Custom short URLs.
- QR codes.
- Click analytics.
- Geographic visitor tracking.
- Link expiration.
- Password-protected URLs.
- Redis caching.
- Load balancing.
- Microservices.

## Future Considerations

Excluded features may be evaluated during Phase 2 planning.

No excluded feature should be implemented without an approved scope change.
